# Knight appearance

The user supplied a personal photo and requested a warm dark-brown skin tone for his knight. Use that reference consistently in every scene and every animation direction.

The current LPC character uses the original `body/male/dark2.png` skin variant, black `messy1` hair and black facial hair. Existing armour layers remain separate. These source sheets are assembled at runtime; a blanket tint is not applied to the armour or character.

The personal photo is a reference only and has not been copied into the site or repository. Source sprite provenance and hashes are recorded in `game-art/character-manifest.json`. The source fetch script preserves the chosen appearance when assets are regenerated.

Validated in the live browser and by checking all directional idle/walk frames. Rear-facing beard frames are intentionally transparent.
