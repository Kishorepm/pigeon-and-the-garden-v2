# The Missing Meal · Stop 02

Sequel to [The Pigeon and the Garden](https://github.com/Kishorepm/pigeon-and-the-garden-v2) (Stop 01, living on `main`).

A tap-through pixel invitation. The throne remains. Lunch does not. The iced glass does not.

Phone portrait first. Tap through. No WASD, no HUD.

## Branches

| Branch | What |
| --- | --- |
| `main` | Stop 01 — original garden invite. Leave it. |
| `stop02-missing-meal` | Stop 02 — this app. Preview until you choose to ship it. |

Do not merge this branch into `main` until Stop 01 has another home (a tag, Pages, or its own project). Merging would replace the original invite.

```bash

```
